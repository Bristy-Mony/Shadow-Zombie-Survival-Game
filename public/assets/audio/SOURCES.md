# Audio asset sources

The Kenney/OpenGameArt sound effects and legacy ambience listed below are released under Creative Commons Zero (CC0 1.0). The supplied Pixabay track is used under the Pixabay Content License; credits are retained for provenance.

- `background.mp3` — user-provided gameplay music, bundled at the user's request (not redistributed as a third-party CC0 asset)
- `horror-music-593677.mp3` — kiravale, **Horror Music**, supplied by the project owner from Pixabay: https://pixabay.com/music/horror-scene-horror-music-593677/

- `laser-shot.ogg`, `laser-impact.ogg` — Kenney, **Sci-Fi Sounds**: https://kenney.nl/assets/sci-fi-sounds
- `zombie-near.wav`, `zombie-attack.wav`, `zombie-die.wav` — artisticdude, **Zombies Sound Pack**: https://opengameart.org/content/zombies-sound-pack
- `dark-ambient.ogg` — congusbongus, **Lost in a bad place (horror ambience loop)**: https://opengameart.org/content/lost-in-a-bad-place-horror-ambience-loop

The original Kenney license text is stored alongside this file as `Kenney-License.txt`.
